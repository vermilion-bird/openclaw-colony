安全模块架构

🔒

输入层

防 Prompt 注入

  • 关键词快速扫描 <50ms
  • 意图分类模型 ~150ms
  • 阻断恶意指令
🔍

处理层

PII 识别脱敏

  • 身份证、手机、银行卡
  • 自定义规则扩展
  • 流式增量处理
🛡️

输出层

合规审查

  • 敏感词黑名单
  • 内容分类模型
  • 流式中断机制
用户消息 → 输入检查 → PII脱敏 → 代理处理 → 输出审查 → 安全响应

快速开始

1
克隆项目
git clone https://github.com/vermilion-bird/openclaw-colony.git
2
配置环境变量
cp .env.example .env # 编辑 .env 设置 NEXTAUTH_SECRET, ENCRYPTION_KEY 等
3
Docker Compose 启动
docker-compose up -d
4
访问管理面板
http://localhost:3000 # 首次访问会引导创建 admin 账号
